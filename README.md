# Python Sales Data Analysis

Projeto desenvolvido para praticar análise de dados com Python, aplicando técnicas de limpeza, transformação e análise exploratória a partir de dados de vendas.

## Tecnologias utilizadas

- Python
- Pandas
- NumPy
- Matplotlib

## Base de dados

O projeto utiliza arquivos CSV e Excel contendo informações como:

- Vendas realizadas
- Lojas
- Clientes
- Produtos
- Gerentes
- Metas mensais

## Etapas do projeto

### Importação dos dados
- Leitura de arquivos CSV
- Leitura de arquivos Excel

### Inspeção dos dados
- Visualização da base de dados
- Verificação de colunas
- Análise estatística inicial

### Tratamento dos dados
- Remoção de colunas desnecessárias
- Tratamento de valores nulos
- Remoção de duplicatas
- Padronização de textos
- Conversão de tipos de dados

### Criação de novas variáveis
Durante a análise foram criadas novas colunas como:

- Faturamento
- Forma de venda
- Região

### Análises realizadas
Foram realizadas análises como:

- Ranking de faturamento por loja
- Produtos mais vendidos no canal online
- Análise de vendas por loja e por produto
- Evolução do faturamento mensal
- Verificação de gerentes que bateram a meta

## Objetivo

Praticar manipulação e análise de dados com Python, simulando situações reais de negócio e desenvolvendo visão analítica.
